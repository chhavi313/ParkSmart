Billing Algorithm Specification

Enforced directly by Java ParkingFeeCalculator service

durationMinutes = differenceInMinutes(entryTime, exitTime);
billedHours = Math.max(1, Math.ceil(durationMinutes / 60.0));
totalParkingFee = billedHours * vehicleHourlyRate;

• Minimum Base Unit: Minimum 1-hour charge applies to any session.

• Ceiling Rule: Any partial hour (e.g. 61 mins) rounds UP to 2 hours.

• Category Tariffs: Bike: ₹20/hr • Car: ₹40/hr • Truck: ₹70/hr.
